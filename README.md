# DSA Lab 05 & 06 — Linked List Applications in C++

## Overview

This repository contains C++ programs for **DSA Lab 05 and DSA Lab 06**. These programs demonstrate the implementation and application of singly linked lists and circular linked lists through Library Management and Blood Donation Management systems.

## Lab 05 — Singly Linked List

### Part A: Library Management System

A menu-driven program that manages book records using a singly linked list.

**Features:**
- Add and remove books
- Insert or remove books at a specified index
- Display all books
- Swap two books
- Sort books by ID
- Reverse the linked list
- Count books and check whether the list is empty

### Part B: Blood Donation Management System

A menu-driven program that manages donor records using a singly linked list.

Each donor record includes an ID, name, blood group, and phone number.

**Features:**
- Add and remove donor records
- Insert or remove donors at a specified index
- Display all donors
- Swap two donor records
- Sort donors by ID
- Reverse the linked list
- Count donors and check whether the list is empty

## Lab 06 — Circular Linked List

### Part A: Library Management System

A menu-driven program that manages book records using a circular linked list, where the last node points back to the first node.

**Features:**
- Add and remove books
- Insert or remove books at a specified index
- Display all books
- Swap two books
- Sort books by ID
- Reverse the circular linked list
- Traverse the list circularly
- Count books and check whether the list is empty

### Part B: Blood Donation Management System

A menu-driven program that manages donor records using a circular linked list.

Each donor record includes an ID, name, blood group, and phone number.

**Features:**
- Add and remove donor records
- Insert or remove donors at a specified index
- Display all donors
- Swap two donor records
- Sort donors by ID
- Reverse the circular linked list
- Traverse the list circularly
- Count donors and check whether the list is empty

- **Data Structures:** Singly Linked List and Circular Linked List

## How to Run

1. Download or clone this repository.
2. Open the required `.cpp` file in Dev-C++.
3. Compile the program.
4. Run the executable.
5. Use the displayed menu to perform the available operations.

Each C++ file is a separate program and should be compiled and run independently.

## Learning Objectives

- Understand singly linked list implementation.
- Understand circular linked list implementation.
- Practice insertion, deletion, traversal, sorting, swapping, and reversal.
- Apply data structures to simple real-world management systems.
- Improve understanding of pointers and dynamic memory allocation in C++.

## Notes

- Each program runs independently.
- Records are maintained in memory during program execution.
- Data is not permanently stored in a file or database.
- The Blood Donation Management programs demonstrate basic donor-record management and are not complete blood bank systems.
